# Agent handoff

## Goal
Build SoloCanvas as a local-first System Architecture & Code Map. Read README.md and context/PLAN.md before starting.

## Status
Planning only. No application code has been implemented or verified in this setup package.

## Coordination
Codex and the other agent take turns on the same branch. Before starting, check whether the other agent has finished, inspect the branch and working tree, and read the latest handoff. Do not overwrite uncommitted work. If ownership or current state is unclear, stop and record the blocker; this document is not a lock.

## Next steps
Add this setup to the repository, settle the first milestone's acceptance criteria and persistence decision, then scaffold and verify the application.

## Handoff after each run
Record date, agent, branch and commit; work completed and changed files; tests and actual results; uncommitted work; blockers and decisions; and concrete next steps. Update periodically during a run as well as at its end. Never include secrets.
